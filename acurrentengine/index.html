Upload endpoint (Power Automate webhook URL)
Until this is set, dropped photos are stored locally only (a thumbnail cache in this browser) and won't reach the client doc. Once set, every dropped photo uploads to Azure Blob through this webhook and the returned URLs ride the JSON round-trip — cross-device, and visible in the client doc.
Field-capture manifest URL (optional)
Photos captured in the field (via the Mac Shortcut) land on Blob and are listed in this manifest. Setting this URL lets the engine pull them into the capture tray to assign to a project. Leave blank if you only add photos directly onto project cards.
